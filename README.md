# გარდაბნის მობილური აკადემია (ალფა ვერსია 1.0.1)

ინტერაქტიული ვებ-პლატფორმა და საგანმანათლებლო რუკა გარდაბნის მუნიციპალიტეტის ახალგაზრდებისთვის.

პროექტის მიზანია გარდაბნის მუნიციპალიტეტში ქართველ და აზერბაიჯანელ ახალგაზრდებს შორის კულტურული დიალოგის, ურთიერთთანამშრომლობისა და არაფორმალური განათლების გაძლიერება მობილური აკადემიის მეშვეობით.

---

## 🌟 ძირითადი შესაძლებლობები

* **🗺️ ინტერაქტიული რუკა (Web GIS)**
  * გარდაბნის მუნიციპალიტეტის ზუსტი საზღვარი და საკვანძო სოფლები.
  * ცენტრალური ჰაბი და მობილური ვორქშოფების ლოკაციები.
  * რუკის სამი რეჟიმი: საგზაო (Roadmap), სატელიტური (Satellite) და რელიეფური (Terrain).
  * 5 კმ რადიუსის დამხმარე არეალების ვიზუალიზაცია.

* **📅 ინტეგრირებული კალენდარი**
  * დაგეგმილი აქტივობებისა და შეხვედრების ოფიციალური განრიგი.
  * თარიღების მიხედვით დეტალური ინფორმაცია და პირდაპირი გადასვლა რუკაზე შესაბამის ლოკაციაზე (`?loc={id}`).

* **👥 მენტორების გვერდი**
  * აკადემიის მენტორთა გუნდის წარდგენა, მათი მიმართულებები და საკონტაქტო თემატიკა.

* **📱 სრული მობილური თავსებადობა (Mobile-First)**
  * სრულად ადაპტირებული დიზაინი ნებისმიერი ზომის სმარტფონზე, პლანშეტსა და მონიტორზე.
  * თითით მართვადი, მოსახერხებელი ნავიგაციის ზოლი და სენსორულ ეკრანებზე მორგებული ელემენტები.

* **☀️ / 🌙 დღისა და ღამის რეჟიმები**
  * ნაგულისხმევად (Default) სუფთა თეთრი დღის რეჟიმი.
  * True Pitch Black ღამის რეჟიმი თვალის ერგონომიული კომფორტისთვის.

* **☁️ მონაცემთა ღრუბლოვანი სინქრონიზაცია**
  * PostgreSQL & Supabase დაცული არქიტექტურა.
  * ავტონომიური ოფლაინ მხარდაჭერა (Graceful Fallback).

## 📁 პროექტის სტრუქტურა

```text
├── index.html / gardabani_map.html   # მთავარი ინტერაქტიული რუკა და პანელი
├── calendar.html                    # ღონისძიებებისა და ვორქშოფების კალენდარი
├── mentors.html                     # აკადემიის მენტორების გვერდი
├── settings.html                    # სისტემის პარამეტრები და ვიზუალური მართვა
├── build_map.js                     # პროექტის ასაწყობი ძირითადი სკრიპტი
├── supabase_config.js               # ღრუბლოვანი სერვისის კონფიგურაციის ფაილი
├── supabase_setup.sql               # მონაცემთა ბაზის სტრუქტურა
├── gardabani_boundary_compact.json  # გარდაბნის გეოგრაფიული საზღვრის GeoJSON
└── verify.js                        # ავტომატური ტესტირების სისტემა
```

## 🚀 ლოკალური გაშვება

პროექტი შექმნილია თანამედროვე ვებ-სტანდარტებით და არ საჭიროებს რთულ დამოკიდებულებებს:

1. **პირდაპირი გახსნა:**
   უბრალოდ გახსენით `index.html` ნებისმიერ თანამედროვე ბრაუზერში (Chrome, Safari, Firefox, Edge).

2. **ლოკალური სერვერით (რეკომენდებულია):**
   ```bash
   # Python-ის გამოყენებით
   python -m http.server 8000
   
   # ან Node.js http-server-ით
   npx http-server .
   ```
   გახსენით `http://localhost:8000` ბრაუზერში.
